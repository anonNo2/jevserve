# JevServe identity

`jevserve-logo.png` is the selected README wordmark. Three paths converge into
one arrow beside a J: several candidates, one decision. Teal and navy keep the
mark legible at small sizes. The white background works consistently in both
GitHub themes. Do not treat the image as a button or stretch its aspect ratio.

Created with the built-in imagegen tool; the final asset is copied into this
repository. No external image hosting is required. Unselected explorations are
not part of the shipped identity.

Initial prompt:

> Design a distinctive horizontal logo for JevServe, an open-source GPU decision
> model HTTP server. An abstract geometric J represents several inputs converging
> to one decision, beside the exact wordmark “JevServe”. Precise flat geometry,
> restrained vivid teal and deep navy, legible at 400 px, approximately 3:1.
> No brain, sparkles, mascot, mockup, slogan, watermark, gradients or 3D.

Final refinement prompt:

> Produce a clean production export on a pure solid white background, with no
> transparency. Preserve the teal converging-paths J and dark navy JevServe
> wordmark. Remove specks, noise and rough edges; use smooth flat shapes and
> pristine lettering, with no outline, texture, gradient or shadow. Keep the
> horizontal composition, exact text, and modest whitespace.
